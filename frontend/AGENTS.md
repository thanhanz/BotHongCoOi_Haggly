# Haggly Frontend Agent Guide

The frontend is intentionally a placeholder until the backend and website
design are ready. Do not add application code here unless the user explicitly
starts frontend implementation.

When frontend work begins, keep React/TypeScript concerns in this directory and
consume the backend through documented HTTP contracts. Do not duplicate Domain
rules or access the database directly. Read the repository-level `AGENTS.md`
and the backend API documentation before adding a feature.

Planned frontend checks will include type-checking, linting, component tests,
and a production build.
